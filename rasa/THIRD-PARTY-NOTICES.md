# Rasa UI / credits and scope

Rasa UI is a Persian-first extension of the FarsiUI foundation. The original upstream copyright and MIT license are preserved in FARSIUI-LICENSE.md. FarsiUI itself builds on shadcn/ui.

- Technical foundation: https://github.com/MiladJoodi/FarsiUI (MIT).
- Interaction design research: https://beui.dev/ and https://github.com/starc007/ui-components. The Rasa extensions are independently written, not redistributed beUI Pro blocks.
- Chart design research: https://evilcharts.com/ and https://github.com/legions-developer/evilcharts. Rasa charts use independent SVG/CSS/React implementations.
- Style research: https://styles.refero.design/. No Refero library, screenshots or third-party DESIGN.md collection is redistributed.

The 12 Rasa extension components and their shared CSS are released under MIT, copyright 2026 Maysam Tashakori / Rasa. FarsiUI-derived Button code retains its upstream license separately. All numeric previews are demonstration data. Component count refers only to the Rasa extension set, not the full upstream catalog.
