# رسا UI / Rasa UI

Persian-first components and interactive product interfaces by Rasa. This repository is a fork of [FarsiUI](https://github.com/MiladJoodi/FarsiUI), preserving upstream history and licensing.

## Rasa extensions

- 12 original Persian React components, with live previews and full source.
- Three preview styles, dark/light examples and accessible interactions.
- Public shadcn-compatible registry with complete CSS and license files.
- [Live gallery](https://rasa-promt.ir/fa/ui) · [Rasa package instructions](rasa/README.md)

```sh
cd rasa
npm install
npm run dev
```

The upstream monorepo remains in this repository. Rasa additions live in `rasa/`; they do not claim ownership of upstream FarsiUI, beUI, EvilCharts or Refero.
